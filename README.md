# Pra-UASA Sains Tahun 5 — Makmal Mini

## Kandungan
- Bahagian A: 21 soalan objektif (21 markah)
- Bahagian B: padanan interaktif dan struktur (9 markah)
- Bahagian C: 5 soalan objektif dan soalan struktur, hipotesis serta penulisan (20 markah)
- Jumlah keseluruhan: 50 markah
- Paparan markah dan popup motivasi berdasarkan pencapaian

## GitHub Pages
1. Ekstrak ZIP.
2. Untuk mengekalkan halaman asal, muat naik folder `pra-uasa-sains-tahun5` ke repository sedia ada dan namakan folder itu `pra-uasa` jika mahu.
3. Pastikan fail `index.html` berada di dalam folder tersebut dan commit changes.
4. URL akan berbentuk `https://USERNAME.github.io/REPOSITORY/pra-uasa/`.

Penilaian struktur automatik berasaskan kata kunci ialah anggaran latihan kendiri; guru boleh menyemak jawapan bertulis secara manual.
